# AWS Serverless File Processing – Project Screenshots

This folder contains visual evidence of the AWS Serverless File Processing project.

The screenshots document the configuration, implementation, testing, and results of the project.

## AWS Services Covered

- Amazon S3 – Input and processed file storage
- Amazon SNS – Event notifications
- Amazon SQS – Message queuing
- AWS Lambda – Automated file processing
- Amazon CloudWatch – Execution logs and monitoring
- Amazon S3 Lifecycle – Object lifecycle management

## Project Evidence

Screenshots are organized to demonstrate the setup and operation of the serverless architecture.

Each screenshot provides evidence of a specific configuration or testing milestone.
